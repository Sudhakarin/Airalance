# Airalance Mobile App

A premium, real-time chat experience. Built with Expo + React Native + Supabase.

## 🚀 Tech Stack

| Layer | Tech |
|-------|------|
| Framework | Expo SDK 54 (React Native 0.81) |
| Router | Expo Router (file-based) |
| Backend | Supabase (Auth + Postgres + Realtime + Storage) |
| Language | TypeScript |
| UI | Custom design system (matches website) |

## 📱 Features

- ✅ **Auth** — Email/password login + signup
- ✅ **Home** — News feed with categories
- ✅ **Status** — Story-style updates (view + create)
- ✅ **Chats** — Real-time messaging with typing indicator
- ✅ **Search** — User discovery + suggestions
- ✅ **Profile** — View/edit + follow system
- ✅ **Notifications** — Connection requests + activity
- ✅ **Settings** — Account + privacy options
- ✅ **Voice messages** — Record + play
- ✅ **Image sharing** — Chat media
