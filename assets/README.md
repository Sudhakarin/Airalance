# Assets Folder

Yeh folder app ke images aur icons rakhta hai.

## Required Files:

| File | Size | Purpose |
|------|------|---------|
| `icon.png` | 1024x1024 | App icon (home screen) |
| `adaptive-icon.png` | 1024x1024 | Android adaptive icon (foreground) |
| `splash.png` | 1284x2778 | Splash screen image |
| `favicon.png` | 48x48 | Web favicon |
| `notification-icon.png` | 96x96 | Android push notification icon |

## Design Guidelines:

**Color palette:**
- Background: `#0A0C12` (ink-900)
- Primary: `#7C5CFF` (violet)
- Accent: `#22D3B8` (teal)

**Icon concept:**
- "A" logo with violet → teal gradient
- Rounded square or circle
- Simple, bold, recognizable at small sizes

**Splash:**
- Centered Airalance logo
- Background: `#0A0C12`

## Kaise Banaye:

Agar aapke paas design files nahi hain, toh:
- **Canva** (free) — canva.com
- **Figma** (free) — figma.com
- **AI tools** — Midjourney, DALL-E

Ya **fallback icon** use karo — Expo default.

## Note:

Agar yeh files nahi hain, toh:
- App **chalega**
- Expo **warning** dega
- Store pe **reject** ho sakta hai (play store / app store)
